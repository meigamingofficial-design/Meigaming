Description

MeiTorrent is a torrent client engineered specifically for Android devices. Designed with a focus on battery conservation and clean UI, it enables seamless torrenting with magnet links, sequential media playback downloading, bandwidth controls, and dark theme support.

Key Features

  • Magnet Link Support: Instant torrent parsing without needing pre-downloaded torrent files.
  • Sequential Downloading: Stream video and audio media files while they download.
  • Wi-Fi Only Mode: Save mobile cellular data with intelligent network connection safeguards.
  • Battery Saver: Auto-pause downloads when device battery reaches custom thresholds.
  • Dark & Light Theme: Native dark mode designed to reduce eye strain and save OLED battery.

System Requirements

OS: Android 8.0 (Oreo) or higher
Storage: 15 MB free disk space
Network: Wi-Fi or Mobile Data connection
