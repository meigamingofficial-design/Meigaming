Privacy Policy for MeiDroid

Effective Date: July 28, 2026

1. Overview

MeiDroid is a desktop application for macOS designed to transfer files between your Mac and connected Android devices via USB connection.

2. Data Handling

MeiDroid collects zero personal data. Transferred files move directly between your connected Android device and your Mac file system over USB. No file data, filenames, or device identifiers are sent to any remote server or cloud service.

3. macOS System Permissions

The Application requires USB bus access and file system access to selected directories on your Mac to read and write transferred files.
